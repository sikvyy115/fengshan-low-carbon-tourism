鳳山智慧低碳旅遊導覽系統－Google Maps 導航 QR Code 與低碳成果頁更新

本次修改基礎：鳳山低碳旅遊_路線站點調整版.zip

新增內容：
1. R01～R04 各自新增 Google Maps 多站步行路線網址。
2. 產生 images/qrcode/R01.png～R04.png 四張 QR Code 圖片。
3. 低碳成果頁會依所選路線顯示對應 QR Code、Google Maps 直接開啟連結及景點順序。
4. 顯示原專題資料中的汽車、捷運／自行車／步行暫估碳排、減碳量及減碳率。
5. 增加碳排估算方法與資料限制說明。

重要使用說明：
- QR Code 的 Google Maps 連結以該路線第一個景點為起點、最後一個景點為終點，中間景點作為途經點，先以步行模式開啟完整景點順序參考。
- 路線內混合捷運、自行車及步行，Google Maps 單一 Directions URL 不保證能在一個連結內完整表示多種交通模式；正式導覽時可依各段交通方式再切換導航模式。
- 原 routes.json 中的 carbon.car、carbon.public 數值為原專題既有資料。本次沒有擅自改寫為實測值，也沒有宣稱已經用實際距離重新計算。頁面明確標示為暫估值，計算基準（每人／每車）、各段里程及排放係數仍須核對後才能作為正式成果。

開啟方式：
1. 解壓縮整個資料夾。
2. 使用 VS Code 開啟「115PBL低碳鳳山」資料夾。
3. 使用 Live Server 開啟 index.html。
4. 進入「推薦旅遊路線」，選擇路線後按「確定」，即可查看 QR Code 與低碳成果。
5. 用手機掃描 QR Code，測試 Google Maps 是否正確帶入該路線景點。

保留項目：原有景點資料、語音檔、交通圖示、四條路線及橫向 RWD 版面均保留。
