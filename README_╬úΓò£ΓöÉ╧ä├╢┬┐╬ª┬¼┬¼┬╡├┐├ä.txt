鳳山智慧低碳旅遊導覽系統－語音導覽整合版

使用方式：
1. 解壓縮整個資料夾。
2. 使用 VS Code 開啟資料夾「115PBL低碳鳳山_整合版」。
3. 使用 Live Server 開啟 index.html（不要直接雙擊 HTML）。
4. 進入景點介紹，點選景點卡片，再點詳細頁的小導遊「介紹」。

目前語音：
- 有中文錄音的景點：F01、S01、S02、S03、S04、S05、S06、T01、T03、T04。
- 英文錄音尚未加入；程式已預留 audio-map.json 中的 *_en.m4a 路徑。
- 若英文檔不存在，會自動略過英文，直接播放已存在的中文音檔。
- 切換頁面、切換景點或瀏覽器頁籤進入背景時，會停止播放。

小導遊圖片：
- 使用原專案 images/guide.jpg（即使用者提供的原圖），沒有重新生成或替換。

注意：
- routes.json 指定的路線示意圖與 QR Code 圖片在原始 ZIP 中未找到；目前程式會容許缺圖，不會因此中斷。
- 溫溼度與 ESP32 通訊尚未接線整合，先保留顯示位置及程式入口。
- 瀏覽器對 M4A 的支援依作業系統與編碼而異；如某台展示電腦無法播放，需將該音檔轉為 MP3/AAC 相容格式再測試。

新版補充：景點詳細頁已調整為「上方置中景點名稱、主圖大幅顯示、右側浮動小導遊、下方重疊白色介紹文字區」的版型；小導遊仍使用 images/guide.jpg。
