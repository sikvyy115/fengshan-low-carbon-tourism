鳳山智慧低碳旅遊導覽系統－RWD 響應式更新版

本版以橫向使用為主要設計：
- 桌上型電腦／筆電：支援 16:9 螢幕（如 1920x1080、1366x768）
- Surface Go：橫向使用
- 其他橫向平板
- 手機橫向瀏覽

本次調整：
1. 各頁面可依內容垂直捲動，避免固定高度造成內容被切掉。
2. 景點列表依螢幕寬度調整欄數。
3. 景點詳細頁主圖維持 4:3，使用 contain，完整呈現照片、不拉伸。
4. 小導遊固定在主圖右下角，圖片等比例縮放。
5. 介紹文字框與景點主圖同寬。
6. 路線頁、低碳成果頁依螢幕寬度調整。
7. 使用原專案的 guide.jpg 圖像內容，另加入透明背景版 guide_transparent.png 並由頁面引用。

使用：
1. 解壓縮 ZIP。
2. VS Code 開啟「115PBL低碳鳳山」資料夾。
3. 以 Live Server 開啟 index.html。
4. 以瀏覽器測試桌機 1920x1080、1366x768，以及 Surface Go 橫向尺寸。

提醒：
RWD 需要在實際裝置與瀏覽器測試；不同瀏覽器縮放比例、Windows 顯示縮放可能使實際排版略有差異。
