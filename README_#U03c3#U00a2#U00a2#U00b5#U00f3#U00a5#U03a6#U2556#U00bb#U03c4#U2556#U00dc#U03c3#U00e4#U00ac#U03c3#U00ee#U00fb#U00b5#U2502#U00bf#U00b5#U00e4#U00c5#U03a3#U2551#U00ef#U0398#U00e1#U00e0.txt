四條推薦旅遊路線優化說明（2026-11-06）

以地理位置相近、順路、低碳步行與自行車為原則。
R01 O13 大東站：大東藝術中心 → 吳記餅舖 → 倆伯羊肉 → 鳳山天公廟（暫保留原順序）
R02 O13 大東站：東便門 → 打鐵街 → 鳳山龍山寺 → 黃埔新村（調整東便門與打鐵街順序）
R03 O12 鳳山站：澄瀾砲台 → 雙慈亭 → 南台春捲 → 明山青草茶 → 老張愛玉 → 鳳儀書院 → 鳳山城隍廟（新增2景點並重排）

重要：路線順序為依據公開地理資訊的初步實用規劃，未經逐段導航測距或現地確認；部分餐飲店位置需再確認，特別是老張愛玉、明山青草茶的實際店址。
